**LM7805 5V Voltage Regulator PCB**

A compact PCB designed using the LM7805 linear voltage regulator to convert an input DC voltage into a stable, regulated 5V DC output. The board supports an input voltage range of 7V to 35V DC and includes input and output filter capacitors for improved voltage stability.

# Features
- Voltage Regulator: LM7805 (TO-220 package)
- Input Voltage: 7V–35V DC
- Output Voltage: Fixed 5V DC
- Input Capacitors: 0.1µF and 10µF
- Output Capacitors: 0.1µF and 10µF
- Thermal Management: Dedicated heatsink mounting provision
- PCB Dimensions: 33.23 mm × 41.19 mm
- Input/Output: 2-pin connectors for easy interfacing

# Applications
- Power supply for microcontrollers and embedded systems
- Arduino and other electronics projects
- Low-power 5V DC circuits
- Prototyping and electronics development

# Note
As the LM7805 is a linear regulator, the voltage difference between input and output is dissipated as heat. A suitable heatsink is recommended for higher input voltages or loads with significant current consumption. Ensure the regulator's current and thermal limits are not exceeded.

Designed for compact, simple, and reliable 5V power regulation.
